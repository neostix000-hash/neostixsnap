Privacy policy

NeostixSnap is a screenshot-to-answer tool for school exercises. It is designed to process a capture once, explain the answer, and forget the screenshot. This page explains exactly what leaves your browser, where it goes, and what is stored.

01 What NeostixSnap processes

Screenshot of the area you select

When you press Alt + Q (or use Snap & Solve), the extension captures the visible tab only after your action. You then drag over the exercise. The selected region is cropped and held in Chrome’s session storage. It is sent to the backend URL configured in Settings when the answer window requests a solution.

On pages where the in-page overlay cannot run, the extension can open a fallback selection window. In that case the visible tab is captured first, held briefly in session storage, and cropped after you select an area. It is removed when the selection is completed or cancelled, or when that window closes.

Recognized question, answer, and steps

The backend returns structured text: the transcribed exercise, a final answer, explanation steps, clarifications, and a confidence value. The extension displays this text in the results window. It is not written to persistent storage. It is copied to your clipboard only if you press Copy.

Settings

The backend URL, an optional extension access token, a default answer language, and an optional model override are stored with chrome.storage.local in your Chrome profile. They stay on your device and are removed when you uninstall the extension or clear its data.

Technical error information

The most recent capture error (an error code and a human-readable message) can be kept in session storage so it can be shown in an error window. It contains no screenshot or recognized exercise text and is discarded when the browser session ends.

02 What is never collected

  • Your browsing history, open tabs, URLs you did not snap, or page content outside the selected area.
  • Keystrokes, mouse activity, form data, passwords, or clipboard contents.
  • Analytics, telemetry, advertising identifiers, or usage profiles.
  • Names, email addresses, accounts, or payment information — the extension has no account system.
  • Persistent copies of screenshots or recognized questions inside the extension.

The extension does not read a page until you invoke a capture. The in-page overlay is injected only for the tab you are capturing and is removed after the selection ends.

03 External AI processing

NeostixSnap is a client for an AI vision backend that you or your organization configure. The backend holds the provider API key. When you request an answer, the backend sends the selected screenshot and instructions to the configured AI provider — for example OpenAI, OpenRouter, Anthropic, a local Ollama server, or another OpenAI-compatible service.

Important

The AI provider processes the screenshot under its own terms and retention policy. NeostixSnap cannot guarantee that a third-party provider deletes data immediately. Review the policy of the provider configured by your backend administrator. For maximum privacy, use a local model such as Ollama so images never leave your machine.

The bundled backend does not write screenshots or recognized questions to its logs. It logs request metadata such as method, path, status, duration, request ID, and error code. Hosting infrastructure outside the bundled code may still record IP addresses, timestamps, or traffic metadata; that depends on where and how the backend operator deploys it.

05 Chrome permissions, explained

activeTab

Grants temporary access to the tab you invoke NeostixSnap on, so it can take a screenshot and show the selection overlay. It does not grant ongoing access to every site you visit.

scripting

Injects the drag-selection overlay into the current tab. The overlay is created only for the capture and removes itself afterwards.

storage

Stores your settings locally and holds screenshots briefly in session memory.

Host access

The extension ships with permission for the default local backend (127.0.0.1:8787 and localhost:8787). For a different backend, Settings requests access only to the origin you enter. The extension does not need host access to the websites you capture.

06 Sharing and sale of data

NeostixSnap does not sell, rent, or share data with advertisers or data brokers. The only external recipient is the backend you configure and, through that backend, the AI provider selected by its operator. If the backend is operated by a school or another organization, that organization controls its own retention and access policies.

07 Security measures

  • Provider API keys stay server-side and are never included in the extension package.
  • An optional shared EXTENSION_TOKEN can require a bearer token for solve requests.
  • The server refuses to bind to a non-loopback address without a token unless explicitly overridden.
  • Settings request host access only for the configured backend origin.
  • HTTPS is strongly recommended for any remote backend; the Settings page warns about plain HTTP.
  • The extension injects its overlay only into the active tab and only when you start a capture.

No system is perfectly secure. Do not capture passwords, payment details, identity documents, or other sensitive personal information.

08 Your controls

  • Reset the backend URL, token, model, and language from Settings.
  • Clear extension data or uninstall NeostixSnap from Chrome to remove local settings.
  • Choose Auto or a fixed answer language at any time.
  • Use a local Ollama backend if screenshots must not leave your device.
  • Close the results window to trigger deletion of the active capture.
  • Configure the backend to reject unknown origins or require an extension token.

09 Schools, students, and backend operators

NeostixSnap is self-hosted software. The person or organization that provides your backend is responsible for the AI provider account, server logs, access control, and any consent or data-protection obligations that apply to student work. If NeostixSnap was installed by your school, contact its administrator with privacy questions.

The open-source project does not operate a central service and does not receive your screenshots. Questions about the project itself can be raised in the issue tracker of the repository from which you obtained it.

10 Changes to this policy

This policy is versioned with the extension. Material changes will be reflected in a new version and in the policy shipped with the extension. Because the extension does not collect contact details, it cannot notify you directly; check this page after an update.

Short version

You choose what to capture. Your backend processes it once. Screenshots are kept in memory only, settings stay in your Chrome profile, and the extension collects no browsing history or analytics.
