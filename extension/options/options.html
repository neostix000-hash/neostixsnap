    Setup checklist

    From clone to first answer.

    1. 01
      Start the backend

      Run the zero-dependency Node server in the project folder.

      cd server && npm start
    2. 02
      Add your AI key

      Copy .env.example to .env and set AI_PROVIDER, AI_MODEL, and AI_API_KEY.

    3. 03
      Connect this page

      Save the backend URL, grant Chrome access, then run a connection test.

    4. 04
      Snap an exercise

      Press Alt + Q, drag over the task, and read the explained answer.

    Privacy by design

    Your AI key stays on the server.

    • Provider API keys are never stored in the extension.
    • Screenshots live only in session memory and are dropped when the answer window closes.
    • The extension collects no browsing history and has no analytics.
    • Images are sent to your backend only after you select an area.
